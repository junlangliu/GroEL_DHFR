# GroEL_DHFR

Code accompanying the preprint:

> **Chaperonin recognition of protein dynamics drives drug resistance**  
> Junlang Liu et al.  
> bioRxiv (2026)  
> https://www.biorxiv.org/content/10.64898/2026.06.03.729952v1

This repository contains the **bioinformatics** and **kinetic modeling** code used in the paper.

| Directory | Contents |
|-----------|----------|
| [`dhfr-aa20-bioinformatics/`](dhfr-aa20-bioinformatics/) | Bioinformatics analysis of DHFR residue 20 |
| [`kinetic_model/`](kinetic_model/) | Analytical kinetic model of GroEL/S rescue of TMP-inhibited M20I DHFR (publication figures) |

**Experimental raw data and data-processing code** are deposited on Zenodo and will be made public upon publication of the article.
