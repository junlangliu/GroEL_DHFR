# Supplemental Methods: DHFR AA20/AA28 and TMP Fitness Analysis

## Data Source

All barcode fitness analyses were performed as a secondary analysis of the DHFR broad mutational scanning dataset generated by Romanowicz, Resnick, Hinton, and Plesa in "Exploring Antibiotic Resistance in Diverse Homologs of the Dihydrofolate Reductase Protein Family through Broad Mutational Scanning" (Science Advances 2025). The source study generated a DropSynth library of 1,536 DHFR homolog designs with two codon-version libraries and assayed barcode recovery in an E. coli ER2566 Delta folA Delta thyA complementation system across a trimethoprim (TMP) concentration gradient.

Raw sequencing reads from the source study were deposited under NCBI BioProject `PRJNA1189478`. The present analysis used the article-derived processed data products provided with that study: collapsed barcode count tables for each assay condition, barcode-to-variant mapping tables for the two codon libraries, and variant annotation tables containing designed homolog identifiers, mutation counts, and protein sequences. Local copies of these article-derived processed data were stored under `/n/home05/zhihuiqi/qzh/IC50/data_raw/`. No barcode collapsing or variant calling was repeated from raw FASTQ files.

## Barcode Filtering, Normalization, and Fitness Definition

Barcode count tables were merged by barcode sequence (`BC`) within each library, and missing condition-specific counts were set to zero. Barcodes were retained if they had a read count of at least 10 in at least one analyzed condition. This threshold was applied at the barcode level. Homolog-level barcode counts were retained as `num_barcodes` and were not uniformly thresholded at five barcodes in the final AA20/AA28 analyses.

For each condition `j`, raw barcode count `c_bj` was normalized to the total read depth of the selected baseline condition:

```text
s_j = sum_b(c_b,baseline) / sum_b(c_b,j)
r_bj = c_bj * s_j
```

where `r_bj` is the depth-normalized count for barcode `b` in condition `j`. Barcode fitness was then calculated as:

```text
F_bj = log2(r_bj + 1) - log2(r_b,baseline + 1)
```

The pseudocount of 1 stabilizes log fold-change estimates for low or zero counts. Positive values indicate enrichment relative to the baseline, whereas negative values indicate depletion. Under TMP selection, higher fitness or a slower decline in fitness with increasing TMP indicates stronger TMP tolerance.

Two baseline definitions were used:

1. Manuscript-style combined analysis: M9 full-supplement baseline (`D03` for lib15, `D04` for lib16).
2. Final AA20/AA28 analysis: lib15 no-drug complementation baseline (`D05`, 0 ug/mL TMP).

The final AA20/AA28 figures use the second definition. Therefore, those fitness values represent TMP-dependent barcode recovery relative to the no-drug complementation condition, not absolute complementation relative to M9 supplement. With this definition:

```text
fitness_0     = log2(D05n + 1) - log2(D05n + 1) = 0
fitness_0_058 = log2(D06n + 1) - log2(D05n + 1)
fitness_0_5   = log2(D07n + 1) - log2(D05n + 1)
fitness_1     = log2(D08n + 1) - log2(D05n + 1)
fitness_10    = log2(D09n + 1) - log2(D05n + 1)
fitness_50    = log2(D10n + 1) - log2(D05n + 1)
fitness_200   = log2(D11n + 1) - log2(D05n + 1)
```

Barcode-level fitness values were joined to the article-derived barcode-to-variant mapping table. For each homolog or mutant, replicate barcode values were summarized by the median:

```text
F_variant,j = median_b(F_bj)
```

Median aggregation was used to reduce sensitivity to barcode-specific outliers.

## Selection of lib15 for Final AA20/AA28 Analyses

The final AA20/AA28 analyses were restricted to lib15/Codon 1. This avoids confounding by codon-version-specific effects in barcode coverage, expression behavior, and normalization. Codon 1 was also the library emphasized for downstream BMS and gain-of-function interpretation in the source study. The final lib15 `mutations == 0` set contained 961 homologs with measured D05-baseline fitness.

## Perfect-Assembly Homolog Analysis (`mutations == 0`)

Perfect-assembly homologs were defined as lib15 variants annotated with `mutations == 0` in the article-derived variant annotation table. These sequences match the designed homolog amino-acid sequence and were used to study residue-state variation among homolog backgrounds. Mutant sequences were excluded from this branch to avoid confounding designed homolog diversity with synthesis-derived substitutions.

Full-length lib15 perfect-assembly protein sequences were intersected with the D05-baseline fitness table and aligned together with the E. coli DHFR reference sequence (`ECOLI_REF`) using MAFFT:

```text
mafft --auto --thread -1
```

Reference coordinates were defined by non-gap residue counting in the E. coli reference row. AA20 was defined as the alignment column containing the 20th non-gap residue of the E. coli reference, and AA28 was defined analogously. In the final full-length alignment:

```text
AA20 = alignment column 42, 1-based
AA28 = alignment column 52, 1-based
```

For each homolog, the amino acids at these alignment columns were extracted. Homologs with gaps or ambiguous residues at the target column were excluded from the corresponding count.

The resulting AA20 count table contained 961 homologs:

## TMP-Response Regression

To summarize TMP-response shape, per-homolog fitness values were regressed against log-transformed positive TMP concentrations:

```text
F = beta0 + beta1 * log10(TMP)
```

The regression used:

```text
0.058, 0.5, 1, 10, 50, 200 ug/mL TMP
```

The 0 ug/mL condition was excluded because `log10(0)` is undefined. `beta0` is the fitted intercept, and `beta1` is the slope with respect to `log10(TMP)`. More negative `beta1` values indicate stronger fitness decline as TMP increases, whereas values closer to zero indicate a flatter TMP response.

Per-homolog regression coefficients were then grouped by AA20/AA28 combination. For each combination, the number of homologs and the 25th, 50th, and 75th percentiles of `beta0` and `beta1` were calculated. Combination-level scatter plots show median `beta0` and `beta1` with interquartile-range error bars; plotted combinations were restricted to groups with at least 10 homologs.

## I/M/L Fitness Distribution and Trend Analysis

Because I, M, and L were the dominant AA20 residue states, the D05-baseline lib15 perfect-assembly table was filtered to homologs with `aa20` in `{I, M, L}`. Fitness values were reshaped to long format for positive TMP concentrations only. For each AA20 group and TMP concentration, the distribution of homolog fitness values was plotted as a violin plot with jittered homolog points and median markers. Smooth group trends were computed by fitting a PCHIP interpolation through the median fitness values for each AA20 state on the `log10(TMP)` scale.

## Single-Mutant AA20 Analysis (`mutations == 1`)

The single-mutant branch was performed separately from the perfect-homolog analysis. Its purpose was to identify lib15 mutants with exactly one amino-acid substitution and test whether that substitution mapped to the E. coli reference AA20 coordinate.

Lib15 barcode mapping rows were separated into `mutations == 1` mutants and `mutations == 0` matched reference homologs. Counts from D05-D11 were processed using the same barcode filtering, D05 normalization, and median aggregation described above. Mutant fitness was summarized by `mutID` and `IDalign`; matched reference fitness was summarized by `IDalign`.

Protein sequences for single mutants and their matched designed references were obtained from the article-derived lib15 variant annotation table. Mutant sequences, matched reference sequences, and the E. coli reference sequence were aligned together with MAFFT. A mutant was retained only if:

1. It had exactly one amino-acid difference relative to its matched designed reference sequence.
2. That single difference mapped to the E. coli AA20 alignment column.
3. Both mutant and reference had D05-baseline TMP fitness estimates.

The filtering produced:

- 5,429 `mutations == 1` mutant IDs with computed fitness.
- 885 matched `mutations == 0` reference homologs.
- 7 single mutants whose only substitution aligned to E. coli AA20.
- 7 final mutant/reference pairs with complete fitness comparison.

For each retained mutant, delta fitness was defined as:

```text
delta_F_TMP = F_mutant,TMP - F_reference,TMP
```

Positive delta values indicate higher mutant fitness than the matched reference homolog at the same TMP concentration. The final panel plot compares each retained mutant fitness curve with its paired reference curve; the 0 ug/mL point is omitted from the x-axis because the plot uses a logarithmic TMP axis.

## folA versus dfrA Sequence-Database Analysis

The folA/dfrA AA20 comparison was independent of the barcode fitness analysis and did not use pooled assay counts. It was designed to estimate amino-acid usage at the P0ABQ4/E. coli folA reference position 20 in broader folA homolog and dfrA-family sequence sets.

Candidate dfr/dhfr/trimethoprim-resistant sequences were downloaded from UniProtKB using:

```text
gene:dfr* OR gene:dhfr*
OR protein_name:"trimethoprim-resistant dihydrofolate reductase"
OR protein_name:"DfrA family"
OR protein_name:"trimethoprim-resistant"
```

This query returned 125,000 raw records. Exact-sequence deduplication produced 124,064 unique records. DHFR-family domains were identified with HMMER using the Pfam DHFR model `PF00186.hmm`:

```text
hmmsearch --cpu 8 -E 1e-3 --domtblout dfr_pf00186.domtblout PF00186.hmm dfr_uniprot_all.fasta
```

All domain HSPs passing the domain-length threshold were extracted, including multiple domains from multi-domain proteins. Sequences containing `*` or `-` were removed, and extracted domain sequences were deduplicated. The final filtered dfr-family domain set contained 2,331 unique sequences.

The folA comparison set was derived from a Pfam-clean DHFR/folA sequence collection clustered with MMseqs2 at threshold 0.5. The representative set contained 1,354 sequences, and 1,355 sequences after adding the P0ABQ4/E. coli folA reference.

Both folA and dfrA sequence sets were mapped to the same P0ABQ4 reference coordinate. AA20 was defined as the alignment column containing the 20th non-gap residue of P0ABQ4. For the final comparison:

- folA sequences excluded the P0ABQ4 reference and headers containing `dfrA`; 1,290 non-gap standard amino acids were counted.
- dfrA sequences were selected from `dfrA_plus_folA_ref_mafft.fasta` using the regex `\bdfrA`; 682 non-gap standard amino acids were counted.

The major AA20 proportions were:

| Group | L | I | M |
|---|---:|---:|---:|
| folA | 830/1290 = 0.643 | 179/1290 = 0.139 | 192/1290 = 0.149 |
| dfrA | 413/682 = 0.606 | 193/682 = 0.283 | 70/682 = 0.103 |

This analysis provides sequence-background evidence that L, I, and M dominate the P0ABQ4-aligned AA20 position in broader DHFR-family sequence space, with the filtered dfrA-family set showing a higher fraction of I.

## Combined Homolog IC50 Analysis

For the manuscript-style combined analysis, lib15 and lib16 perfect assemblies were processed using the M9 full-supplement baseline (`D03` for lib15 and `D04` for lib16). Perfect-assembly homolog fitness values were aggregated by `IDalign`, and IC50 was estimated from the seven TMP concentrations using a four-parameter logistic model:

```text
F = bottom + (top - bottom) / (1 + (TMP / IC50)^hill)
```

Fits were performed with `scipy.optimize.curve_fit`. Parameter bounds were:

- `IC50`: 1e-6 to 1e4.
- `hill`: 0.01 to 10.
- `bottom` and `top`: observed fitness range plus or minus 10.

For each fit, the output included IC50, Hill coefficient, bottom, top, R-squared, number of fitted points, fit status, barcode count, and number of represented codon libraries.

## Software

Analyses were performed with Python scripts using `pandas`, `numpy`, `scipy`, `matplotlib`, `seaborn`, and Biopython. Multiple sequence alignments were generated with MAFFT. DHFR-domain detection in the dfrA-family sequence analysis used HMMER with Pfam model PF00186. MMseqs2-clustered folA representative sets were used for the external folA background comparison.
